# Entwicklungsakte autonomer Verladearm (ISO 9001, Kap. 8.3)

Stand 30.10.2026 · Entwurf · Aufbau vorläufig, wird an die HETA-Vorlage angepasst, sobald sie
vorliegt.

Die Akte ordnet die vorhandenen Unterlagen den Anforderungen von ISO 9001:2015, Kapitel 8.3
(Entwicklung) zu. Inhalte werden nicht doppelt geführt: Die Akte verweist auf die Fachdokumente
im Repository; Nachweise sind dort bzw. in der Git-Historie abgelegt.

| ISO 9001 | Dokument | Inhalt |
|---|---|---|
| 8.3.2 Planung | [Entwicklungsplan](entwicklungsplan.md) | Phasen, Meilensteine, Zuständigkeiten, geplante Reviews |
| 8.3.3 Eingaben | [Lastenheft](../lastenheft.html), [BASF H517](../kunde_basf_h517.md) | Anforderungen Kunde, Normen, Randbedingungen |
| 8.3.4 Steuerung | [Reviews](reviews.md), [Anforderungsnachweis](anforderungsnachweis.md) | Bewertungen mit Ergebnis, Verifizierung und Validierung je Anforderung |
| 8.3.5 Ergebnisse | [Dokumentenliste](dokumentenliste.md) | Entwicklungsergebnisse mit Version und Freigabestatus |
| 8.3.6 Änderungen | [Änderungen](aenderungen.md) | Änderungen mit Grund, Auswirkung und Freigabe |

**Freigaben:** Felder „Freigabe“ sind von den genannten Verantwortlichen mit Name und Datum zu
füllen (bzw. nach HETA-Vorgabe zu unterschreiben). Einträge ohne Freigabe gelten als Entwurf.

**Ablage:** Repository `autonomer-verladearm`, Branch `main`. Jede Änderung ist über die
Git-Historie (Datum, Autor, Begründung) nachvollziehbar; vertrauliche Kundenunterlagen (z. B.
Fotos BASF) liegen nicht im Repository.
