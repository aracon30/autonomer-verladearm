# 3D-Erklärseite Verladearm (intern)

`Verladearm_3D_intern.html` im Browser öffnen (offline, keine Installation). Zeigt den Ablauf einer
Verladung (Job 1–3, Eintauchen, Nachziehen, Spülen, Pendelwanne, Rückfahrt) mit Achswinkeln,
Füllstand, Klappe und Pumpe. Maus: drehen/zoomen; Schritte rechts anklickbar; Zeitleiste unten.
Vereinfachte Kinematik (Maße `heta_prototyp.yaml`), keine Konstruktionsdaten der Abdeckung.

Quelle: `verladearm-live/` (main.js, style.css), gebaut mit dem Skill
[teardown](https://github.com/elvarofficial/teardown) (MIT): `node sims/build.mjs <ordner>`.
